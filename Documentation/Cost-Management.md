# Cost Management

## Purpose

Cost Management is used to monitor and optimize Azure spending for the Online Learning Portal.

## Features Used

Cost Analysis
Cost Forecasting
Budget Alerts

## Benefits

Prevents overspending
Improves cost visibility
Supports cloud governance

## Budget

A monthly budget of R500 was configured for the development environment.

## Monitored Resources

Azure Storage Account
Azure SQL Database
Azure SQL Server
Azure Key Vault
