Role-Based Access Control (RBAC)

Overview

The Online Learning Portal uses Role-Based Access Control (RBAC) to enforce the principle of least privilege.

Student

Permissions
View Courses
View Assignments
Submit Assignments
View Results
Manage Own Profile

Restrictions

Cannot Delete Data
Cannot Manage Users
Cannot Modify Results

Lecturer

Permissions

Create Assignments
Update Assignments
View Submissions
Grade Assignments
Publish Results

Restrictions

Cannot Manage Azure Resources
Cannot Manage Security Policies


Administrator

Permissions

Manage Azure Resources
Manage Security Policies
Manage Users
Manage RBAC
Manage Key Vault
Manage SQL Database

Security Principle

The design follows the Principle of Least Privilege and Zero Trust Security.
